---
name: playbill-implement
description: Make a scoped implementation or correction that satisfies a task's acceptance criteria and preserves surrounding behavior.
---

Read the supplied task, relevant source, and applicable repository instructions.
Identify the smallest coherent change that satisfies the requested behavior. Match
existing interfaces and conventions; preserve unrelated edits and documented
compatibility constraints. For a correction, connect each changed behavior to the
reported finding or tested hypothesis.

Use focused regression checks for behavior at risk, including the original failure
case. Record files changed, commands actually run, full outcomes, and remaining
limitations in the requested implementation evidence. Distinguish an implemented
change from a passing check and a passing check from acceptance of the whole task.
